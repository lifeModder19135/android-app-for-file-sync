Status values: `open`, `investigating`, `fixed`, `wontfix`, `not-app` (emulator/system issue).

| 7 | 2026-10-17 | Empty files failed the similarity check (read as 0% alike), so sets with empty files never synced. All empty: sync pauses, baselines stay blank, until one file is written to; then the rest are filled with no checks. Several non-empty files: the similarity check runs on those only. Added unit tests for single-word files, short-text thresholds, common-word-only text, and the existing long-text safeguards. |
| 9 | 2026-10-18 | User may be unable to return from an external editor such as Markor if its own navigation or Back control is unavailable. | fixed | Added an opt-in Android “display over other apps” permission flow and a temporary **Return to SyncAssist** overlay while an external editor is open. | 11 | 2026-10-18 | Blank files should not cause repeated dissimilar-file warnings. | fixed | The similarity evaluator itself now excludes blank/whitespace-only contents from both filename and content checks. Added tests including unrelated names on blank files. |
